# Wren's C# Godot Sharepack

This is a work in progress project for a bunch of different components, entities, managers, and plugins I built and like to share between projects. Feel free to use and change as much as you'd like, and if you have any interesting ideas, please feel free to create a PR and offer to merge into this pack! Anyone is entitled to use this pack in their games, all I ask is that you add me and anyone else who has worked on this pack to the list of credits for your game. I'll be keeping a running tally of who has worked on this in a separate file, but as of now (July 27th, 2026) I am the only person who has worked on this pack, minus the authors of the plugins.
